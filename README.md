# SMARTRICH Official Website

Enterprise-grade B2B website scaffold built with Next.js App Router, TypeScript, and Tailwind CSS.

## Structure

- `app/` — Next.js app router pages and global styling
- `components/` — modular UI components
- `lib/content.ts` — structured homepage content data
- `tailwind.config.ts` — Tailwind CSS configuration

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Design principles

- Clean, minimal enterprise aesthetic
- Reusable modular components
- Tailwind CSS only, no inline styles
- Strong typography, spacing, and clarity
